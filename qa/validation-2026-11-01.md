- `npm test`: 12개 동작 테스트 통과. URL 정규화, 중복 제거, 선택 유지, Windows 파일명, 부분 추출 내보내기, 로그인/출처 확인, RPC 파싱, 빈 본문/응답 변경/429 처리.
- `npm run check`: manifest, 참조 파일·아이콘, JavaScript 문법, HTML 인라인 스크립트 정책, 사이트 권한 범위 확인.
- 실제 YouTube 검색 결과에서 수집 함수를 실행해 일반 영상 18개의 정규 URL·제목·채널명을 확인. 쇼츠와 광고는 수집 대상에서 제외.
- 브라우저 UI 테스트: 영상 수집, 선택 해제, 새로고침 후 목록·선택 보관, 노트북으로 이동하는 인계 화면.
- 테스트용 Notebook 응답으로 소스 목록 → 추출 → Markdown 실제 다운로드 확인. 실패 소스 목록과 숫자 문단 보존 확인.
- 실패 소스 한 건을 재시도할 때 그 소스에 대해서만 한 번 요청되는지 확인.
- 8개 소스 추출 도중 중지: 진행 중 3건만 마치고, 대기 중 5건을 새로 요청하지 않는지 확인.
- 폭 380px 패널 화면 검수. 수평 넘침 없음. 많은 소스는 목록 내부에서 스크롤.

## 미검증 범위

- 실제 Chrome/Edge에 설치한 뒤 `chrome.scripting`/Side Panel 권한까지 포함한 통합 실행은 아직 하지 않았습니다. 테스트 브라우저에서는 확장 프로그램 로딩 CDP 기능을 제공하지 않았습니다.
- 실제 사용자 계정의 노트북 소스 목록·본문을 요청하지 않았습니다. Notebook 응답은 원본 북마클릿 구조를 바탕으로 한 테스트 데이터로 검증했습니다.
- 유튜브 채널·재생목록의 모든 레이아웃 변형, 브라우저별 설치 UI는 실화면 검증 범위에 포함하지 않았습니다.
