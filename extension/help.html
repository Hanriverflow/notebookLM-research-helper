북마클릿 대신,
버튼 하나로 자료를 모으세요.

유튜브 영상 모으기와 노트북 자료 저장을
브라우저 옆 패널 한곳에서.

처음 한 번

확장 프로그램 설치

  1. 크롬 주소창에 chrome://extensions를 입력하세요.
    엣지는 edge://extensions를 입력하면 됩니다.
  2. 개발자 모드를 켜고 압축해제된 확장 프로그램을 로드합니다를 누르세요.
  3. extension 폴더를 선택하세요.
    manifest.json 파일이 들어 있는 폴더입니다. ZIP 파일은 먼저 압축을 풀어 주세요.
  4. 주소창 옆 퍼즐 모양 → 리서치 포켓 → 고정을 누르세요.
    이제 포켓 아이콘을 클릭하면 옆 패널이 열립니다.
01 / 영상 모으기

링크를 한 번에

  1. 유튜브에서 검색하거나 채널의 동영상 탭을 엽니다.
  2. 포켓 아이콘을 눌러 이 탭에서 영상 모으기를 클릭합니다.
  3. 원하는 영상을 선택하고 링크 복사하고 노트북 열기를 클릭합니다.
  4. 노트북에서 소스 추가 → 웹사이트를 열고 Ctrl+V로 붙여 넣습니다.
02 / 자료 저장

본문을 한 파일로

  1. 소스 가져오기가 끝난 노트북을 엽니다.
  2. 패널의 자료 저장에서 현재 창의 노트북을 선택하고 소스 불러오기를 클릭합니다.
  3. 필요한 소스를 선택하고 선택한 자료 최신 본문 추출을 누릅니다.
  4. .md 파일 저장으로 내려받습니다. AI 채팅에 첨부하거나 Obsidian으로 옮기세요.

사용하다 막혔다면

영상 모으기 버튼이 비활성화돼요.
같은 브라우저 창에서 유튜브 탭을 선택해 주세요. 홈·쇼츠 화면에서는 검색 결과나 채널 동영상 탭으로 이동해 주세요.
모은 영상을 정리하고 싶어요.
제목·채널·주소로 검색할 수 있습니다. 전체 선택은 표시된 영상에만 적용됩니다. 선택 삭제는 검색 밖에서 선택한 영상도 포함하며 버튼에 개수가 표시됩니다. 삭제 취소는 5분 동안 한 번 사용할 수 있고 다른 패널의 추가·선택 변경을 보존합니다. 브라우저 전체 목록은 최대 500개입니다.
어느 노트북에서 자료를 읽나요?
자료 저장의 노트북 선택 목록에서 현재 창의 개별 탭을 고르세요. 활성 탭을 바꿔도 선택한 대상은 유지됩니다. 탭을 닫으면 다른 노트북을 직접 선택해야 합니다. 로그인과 로딩이 끝난 뒤 소스를 불러오세요.
최신 본문 추출과 재시도는 어떻게 다른가요?
최신 본문 추출은 선택한 모든 소스를 다시 읽습니다. 실패·미완료 자료 재시도는 본문이 없거나 최근 요청이 실패·중단된 소스만 읽습니다. 갱신에 실패해도 이전 성공 본문을 보존하고 저장 파일에 추출 시각과 갱신 실패를 표시합니다.
일부 자료만 추출됐어요.
실패·미완료 자료 재시도 버튼을 누르세요. 목록에서 해석하지 못한 항목과 중복 ID는 화면과 저장 파일의 누락 절에 남깁니다. 본문 없이 누락만 있어도 보고서를 저장할 수 있습니다. 유튜브 영상은 공개 영상의 자막이 있어야 합니다.
요청이 많다는 안내가 나와요.
새 요청을 멈추고 이미 진행 중인 요청만 정리합니다. 표시된 시각 이후에 재시도 버튼을 직접 눌러 주세요. 자동으로 다시 시작하지 않습니다. 중지 버튼을 누른 뒤에도 진행 중인 요청이 끝날 때까지 새 작업을 시작할 수 없습니다.
추출 중 패널을 닫아도 되나요?
영상 목록은 보관됩니다. 노트북 본문은 패널 메모리에만 있으며 패널을 닫으면 사라집니다. 추출이 끝나면 먼저 파일로 저장해 주세요.
API 키나 별도 서버 없이 사용합니다. 영상 목록은 이 브라우저에 보관하고, 노트북 본문은 저장 버튼을 눌러 파일로 내려받습니다.
자료를 AI 채팅에 넣거나 노트북의 소스로 추가하는 것은 사용자가 직접 선택합니다.
